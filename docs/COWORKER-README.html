CLOUDASTA · FICTIONAL DEMO · ADMINISTRATOR WORKSPACE

Knowledge Studio

Find duplicate files, compare new and old knowledge, review uncertain changes, and ask questions with original source citations. Everything in this workspace is fictional.

Get started

Ask the operator to start the app with npm start, then open http://127.0.0.1:4173. No sign-in is needed.

  1. Generate demo files. Create 30 fictional SOPs, proposal decks, QBR notes, pricing frameworks and Meet transcripts.
  2. Build the full index. In File library, index every readable file for keyword and semantic search.
  3. Start cleanup. In Agent workspace, watch searches, reads and decisions as the agent works newest to oldest.
  4. Review the exceptions. Open the customer onboarding kickoff amendment. Approve the partial change; the older SOP’s security and handoff sections stay valid.
  5. Ask a question. Ask “How quickly should customer kickoff be scheduled?” Open the citation and check the new three-day rule.

Processed means analysis and required decisions are complete. Processor shows Agent or Administrator. Waiting or failed files remain unprocessed. Old files may still contain valid, unchanged sections.

Understand the execution mode

Local evidence planner uses actual retrieval and evidence rules, with no LLM inference. Live Qwen requires an operator-configured model endpoint. The interface identifies which mode ran.

If it breaks

No evidence? Check indexing, approval and effective dates. Paused? Resume the workspace and saved run. Failed file? Inspect its error and re-analyze. Model unavailable? Use the labelled local planner. Need to recover? Inspect Activity & recovery; later changes may block rollback. Reset demo files to start over.

Original files are preserved. No real email or company sources are connected. This is a local demonstration, not a production service.
